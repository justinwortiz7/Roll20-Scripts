# Roll20 API Scripts Collection

A curated collection of custom API scripts designed to enhance your Roll20 tabletop gaming experience. These scripts provide additional functionality and automation for your Dungeons & Dragons and other tabletop RPG campaigns.

## ⚠️ Requirements

Before using these scripts, ensure you have:

- **Roll20 Pro Subscription**: API scripts require a Roll20 Pro subscription to function
- **Game Master Permissions**: Only Game Masters can install and configure API scripts
- **Basic JavaScript Knowledge**: Helpful for customization and troubleshooting

## 🤔 How to Install

For detailed installation instructions, visit [Intro to Roll20 API Scripts: How do I install external API scripts?](https://help.roll20.net/hc/en-us/articles/360037256714-Introduction-to-Mod-Scripts-API#API-HowdoIinstallanAPIscriptifIwanttowritemyowncodeorIwanttousecodefromanexternalsource?).
